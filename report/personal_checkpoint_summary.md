我们已经把“数据 → 特征 → 调参 → 预测 → 误差区间 → 提交文件”跑通。核心课程模型是 **L2 Logistic Regression**，同时保留“只看电影历史高分比例”的简单参考。

## 结果怎么理解

| 方法 | Precision | Recall | AP |
|---|---:|---:|---:|
| 只看电影高分比例 | 73.99% | 50.75% | 0.7338 |
| Logistic Regression | **81.93%** | **50.16%** | **0.8067** |

- **Precision 81.93%**：在验证集里，模型判断“会给高分”的电影评分记录中，约 82% 确实是 4–5 分。
- **Recall 50.16%**：验证集中真正的高分记录，模型找回了约一半。我们选择的是较保守的推荐门槛，不是尽量推荐更多电影。
- **AP 0.8067**：衡量整个分数排序对高分记录的区分能力，不依赖这一个推荐门槛；它不是“80.67% 的准确率”。
- LR 的 precision 比简单参考高 **7.94 个百分点**，配对用户 bootstrap 区间为 **[6.07, 9.94] 个百分点**。
- LR precision 的 95% 区间为 **[80.40%, 83.39%]**，AP 的区间为 **[0.7914, 0.8203]**。

结论：九个历史特征的 LR 是一个有用的 baseline，当前验证结果优于非个性化参考。还不能说 GNN 有用，因为它没有训练；也不能把这里的结果当作最终测试成绩或全电影目录上的推荐成功率。

## 为什么结果相对可信，又有哪些限制

- 100,000 条评分按用户随机划分；实际使用 61,175 条历史评分、19,585 条训练目标、9,575 条验证目标。9,570 条合格测试记录仍封存。
- 九个特征和图只用历史记录构建；每个 CV 折单独做标准化。
- 2,000 次 bootstrap 按用户抽样，保留同一用户记录之间的相关性。
- 阈值仍是在验证集挑选的，因此 precision 区间不包含挑选阈值和训练过程的不确定性；报告明确说明了这一点。
- 只跑一组开发划分，没有尝试许多随机种子后挑最好结果。
- 14 项自动测试通过；两个 baseline 已独立复现，指标、阈值及 bootstrap 数组一致。
